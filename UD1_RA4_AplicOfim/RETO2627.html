Reto: Montamos una academia online

Una empresa nos pide que realicemos una academia online de ofimática para sus empleados. El proyecto propone al alumnado que realice todas las acciones necesarias para la puesta en marcha de una academia de aprendizaje a distancia.

Requisitos

  • Generar contenido para la formación online

    • Videotutoriales y manuales de las aplicaciones de ofimática web más utilizadas de Microsoft Office, cómo:
      • Word para la creación de documentos
      • Teams para videoconferencias
      • Excel para la gestión de datos
      • Formulario de contacto

  • Instalación de un cliente de correo y configuración de cuentas de correo electrónico.

    • Instalación de un cliente de correo electrónico (Thunderbird)
    • Configuración de cuentas de correo electrónico (Gmail, Outlook, Yahoo, etc.)
    • Prueba de envío y recepción de correos electrónicos
    • Documentación del proceso de instalación y configuración del cliente de correo electrónico
    • Creación de un manual de usuario del cliente de correo electrónico

  • Instalación de un gestor de documentos Nextcloud sobre Docker.

    • Instalación de Nextcloud sobre Docker
    • Configuración de cuentas de usuario en Nextcloud
    • Pruebas de subida y descarga de documentos en Nextcloud

  • Creación de un curso online

    • Instalación de un Moodle con Docker
    • Creación de un curso online con Moodle
    • Dotación de contenido al curso online

  • Creación de una página web

    • CMS (instalación y configuración de WordPress)
    • Aspecto estético de la web ( diseño visual, secciones)
    • Elementos de la web ( menú, contenido, páginas, entradas, formularios, medio audiovisual, enlaces)
    • Tienda e-commerce ( productos, envío, facturas)
    • Usuarios y grupos (administración)

Gestión del proyecto

  • Tablero Trello para la gestión del proyecto
  • Ofimática con Microsoft 365 (Word, Excel, PowerPoint, OneDrive, Teams)
  • Carpeta compartida con el equipo de trabajo en OneDrive

Presentaciones

  • Interactúa con la audiencias cuando realiza la presentación del proyecto

    • No establece contacto visual con la audiencia. No responde a las preguntas.
    • Establece muy poco contacto visual con la audiencia. Responde a las preguntas de manera confusa e incompleta
    • Establece poco contacto visual con la audiencia. Responde a las preguntas de manera incompleta
    • Establece contacto visual con una audiencia. Responde bien a la mayoría de las preguntas
    • Establece contacto visual con toda la audiencia. Responde correctamente todas a las preguntas.

  • Usa recursos visuales cuando realiza la presentación del proyecto

    • No utiliza recursos audiovisuales
    • Los recursos audiovisuales son insuficientes y no se relacionan con el tema
    • Incorpora muy pocos recursos audiovisuales y no están claramente relacionados con el tema
    • Utiliza recursos audiovisuales suficientes para apoyar la exposición
    • Utiliza variados recursos audiovisuales que ayudan a la comprensión del tema

  • Expresa con corrección cuando realiza la presentación del proyecto

    • No presenta.
    • Presenta demasiados problemas para hablar con el volumen adecuado o para articular las palabras, por lo que resulta muy difícil entender la exposición.
    • Presenta problemas para pronunciar algunas palabras, y se esfuerza al hablar, no logrando que se entienda ciertas partes de la exposición y sea escuchado con claridad por todos.
    • Pronuncia algunas palabras de forma incorrecta, y habla suficientemente alto para ser escuchado con claridad, aunque con altibajos.
    • Pronuncia todas las palabras correctamente y habla suficientemente alto para ser escuchado con claridad, todo ello con buena vocalización entonación adecuada.

  • Ajusta al tiempo indicado cuando realiza la presentación del proyecto

    • No presenta.
    • Tiene demasiados problemas con el uso del tiempo. Se extiende demasiado o no alcanza a abarcar todos los aspectos del tema.
    • Tiene algunos problemas con el uso del tiempo. Termina la exposición muy pronto o no logra terminarla.
    • Hace un uso adecuado del tiempo, pero algunos aspectos del tema son tratados con prisa.
    • Hace un uso adecuado del tiempo asignado y logra abarcar todos los aspectos del tema.
